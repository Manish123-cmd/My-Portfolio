# Manish Kafle — Portfolio

Personal portfolio built with HTML, CSS, JavaScript, and GSAP.

## Preview

Serve this directory with a local web server, such as VS Code Live Server, and open `index.html`.

## Contact form

The form uses FormSubmit to send messages to kaflemanish452@gmail.com. On first use, confirm the activation email from FormSubmit, then send a fresh message to check delivery. Keep the default spam protection enabled.

Messages include the visitor's name, email, subject, message, and browser-generated submission timestamps in UTC and Europe/London time. The received email also has its own delivery timestamp.

## Files

- `index.html`: page content and form configuration
- `style.css`: styling and responsive layouts
- `script.js`: animations and form validation
- `Assests/`: images, fonts, and bundled animation libraries
